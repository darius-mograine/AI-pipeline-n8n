Main branch

Здесь хранится последняя стабильная версия пайплайна без ошибок. Данная версия работает на моделях Groq + Cloudflare Workers AI.

Card — папка с генерациями текущей версии пайплайна.
CardPipeline — json для n8n, необходимый для работы бота и генерации.
start_n8n.bat — запуск n8n со всеми необходимыми разрешениями одной кнопкой.
Results_1/2.png — скриншот-демонстрация из тг-бота, результат, полученный в текущей версии.

После клонирования репозитория выполните `git config core.hooksPath .githooks`, чтобы включить pre-commit хук, который блокирует коммиты с API-ключами/токенами (см. .githooks/pre-commit).
